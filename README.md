# Umbra

A macOS-inspired desktop shell for Wayland, built with Quickshell and QML.

Umbra aims to bring a clean, cohesive desktop experience to Linux through a custom top bar, dock, application launcher, control center, notifications, and more.

## Features

- macOS-inspired top bar and dock
- Application launcher and search
- Notification center and quick settings
- Audio, network, and Bluetooth controls
- Media playback controls
- Customizable themes, colors, and wallpapers
- Wayland-first design
- Modular architecture with compositor-specific integrations

## Tech Stack

- Quickshell
- Qt 6
- QML
- JavaScript
- Wayland

## Requirements

- Linux running a Wayland compositor
- Quickshell
- Qt 6 and the required Qt Quick modules

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/umbra.git
cd umbra
```

Run the shell:

```bash
qs -c umbra
```

Refer to the documentation for compositor-specific setup and configuration.
