
# Umbra

A macOS-inspired Wayland desktop shell built with Quickshell and QML.

## What is this?

Umbra is a personal project where I'm messing around with the idea of bringing a macOS-inspired desktop experience to Linux. Think top bars, docks, launchers, and other desktop shell features, all built around Quickshell.

Before anyone gets their expectations up, this project is around 80% vibe-coded. There's AI-generated code, questionable decisions, probably some terrible practices, and a decent chance that something breaks when you least expect it.

This is not some professional-grade project, a polished product, or something I'm promising to maintain forever. I'm building it because I think it's cool and I want to see where it goes.

## Expectations

- Bugs? Probably.
- Scuffed code? Absolutely.
- Unfinished features? Most likely.
- Random breakage? Wouldn't be surprising.
- Consistent updates? Don't count on it.
- Production-ready stability? Don't make me laugh.

Features might change, things might get rewritten, and some ideas might never make it past the planning stage. I'm not promising anything, and I'm not going to pretend this is something it isn't.
